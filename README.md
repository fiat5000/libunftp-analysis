# libunftp-analysis

本リポジトリは、Rust製の非同期FTP(S)サーバーライブラリである [Cloudinvoke/libunftp](https://github.com/Cloudinvoke/libunftp) のソースコードおよびアーキテクチャを解析し、**Google Antigravity** を利用して生成した内部設計書・アーキテクチャ図・シーケンス図をまとめたドキュメントリポジトリです。

---

## 📌 解析対象リポジトリ

- **対象プロジェクト**: [libunftp](https://github.com/Cloudinvoke/libunftp)
- **生成ツール**: Google Antigravity

---

## 📂 ドキュメント構成

詳細設計書および各Mermaid図・解説は [`docs/detailed_design/`](./docs/detailed_design/) 配下に格納されています。一覧と概要については [`docs/detailed_design/README.md`](./docs/detailed_design/README.md) を参照してください。
